# 等号搬运工 · 移项小实验

一个面向小学四年级课堂的移项互动演示。学生直接拖动方程中的数字、3x 里的 3，或 x，跨过等号时符号和运算实时翻转；后面的关卡还会把“搬 3x 里的 3”“两边都有 x”和“手动配对合并同类项”做成可操作的多步过程。

当前题库共 **22 关**，按难度从加减移项、带 3x 的方程、同边合并、两边都有 x，逐步走到带负 x 的挑战题。关卡需要按顺序解锁；全部完成后会获得“解方程之王”称号。

![基础界面](preview.png)

## 快速开始

有两种打开方式：

- **单文件版（推荐课堂使用）**：双击 `equation-mover-standalone.html`，一个文件就是完整应用，方便拷到教室电脑或 U 盘。
- **源码版**：双击 `index.html`，需要和 `styles.css`、`app.js` 放在同一个文件夹里。

建议按 `F11` 进入全屏，适合投影或触控一体机。第一次使用可以点右上角的 `?` 查看玩法说明。

支持鼠标拖动、触摸屏拖动，也支持键盘操作。

## 进阶动作

### 1. 搬 3x 里的 3：乘变除

`3x` 就是 `3 乘 x`，卡片上的 3 和 x 之间会显示一个小 `×`：

![3 × x 的卡片](preview-times.png)

遇到 `3x = 12` 时，拖住 `3x` 左边金色的 **3**，跨过等号：

```text
3x = 12   →   x = 12 ÷ 3   →   x = 4
```

整张 `3x` 卡片也可以拖动，那代表把整项移项；拖金色数字则是“除以这个数”。为了避免把其他项漏除，只有 `3x` 已经单独留在一边、另一边是一个数时，金色数字才会亮起并允许拖动。

![乘变除演示](preview-coefficient.png)

### 2. 两边都有 x：先搬到一起，再合并

遇到 `2x = x + 4` 时，先把右边的 `x` 搬到左边：

```text
2x = x + 4   →   2x - x = 4   →   x = 4
```

遇到 `3x + 2 = x + 8` 时，步骤会更多：

```text
3x + 2 = x + 8
→ 3x + 2 - x = 8       （拖过来的 x 放在最后）
→ 3x - x = 8 - 2
→ 配对两个 x 项，填 2
→ 2x = 8 - 2
→ 点“算一算”得到 2x = 6
→ x = 6 ÷ 2
→ x = 3
```

![两边都有 x](preview-both-sides.png)

### 3. 手动配对：只有 x 项需要配对

带多个 x 项的关卡会多一步“配对合并”：

```text
3x - x
→ 把 3x 拖到 -x 上
→ 出现一条连线
→ 直接填：合并后是 [ ]x
→ 变成 2x
```

配对成功后，方程上会出现一条弧线连接两个 x 项，下方只给一个输入框：

```text
合并后是 [ ] x
```

**不显示原算式，也不提示先算哪一步**，学生需要自己判断合并后的 x 前面的数。填错不会直接合并，只提示再试一次；也可以取消配对。

数字之间不需要拖动配对：点“算一算”会自动把数字算成一个数。

![配对合并](preview-pairing.png)

## 课堂玩法

1. 先不急着算，问学生：**“要让 x 单独留下，谁挡住它了？”**
2. 请学生上台，把挡路的项拖到等号另一边。
3. 停在拖拽预览上，让学生观察：**“跨过等号以后，+3 变成了什么？×3 又变成了什么？”**
4. 当 x 都到了同一边、数字都到了另一边，先让学生找 x 项。
5. 在配对关里，把一个 x 项拖到另一个 x 项上，出现连线后直接填“合并后是几 x”。
6. 数字不用配对，点“算一算”自动算成一个数。
7. 如果 x 前面还有数字，继续把金色数字拖到另一边，变成除法。
8. 解出后读一读检验式，例如 `3 × 4 = 12 ✓`，养成代回检验的习惯。

侧边栏的口诀是：

> 跨过等号，加变减，减变加；乘变除，除变乘。

拖到同一边或空白处会弹回，不改变方程；这正好可以用来对比“没有跨过等号，就不变号”。

### 界面上的“提示”怎么用

- 页面顶部固定显示当前题的**原方程**，不再直接写出“把 5 搬到右边”这类操作答案。
- 下方默认只提示“拖动方程中的项，观察等号两边怎样变化”，先让学生自己判断。
- 点左下角的 **“提示”** 按钮，才会高亮下一步该拖的项，并在下方显示一步操作提示；约 3.6 秒后自动收起。
- 拖动过程中仍会实时显示“跨过等号，+5 变成 -5”这类预览，方便观察规律。

### 负数预警

当同一边的多个 x 项合起来会得到负数时，例如 `2x - 5x` 或 `-2x - x`，这些 x 项会：

- 变成红色边框，金色数字块也变红；
- 右上角出现红色“负”标记；
- 点“提示”会说明“红色 x 项合起来是负数，先把负项搬到另一边”；
- 如果仍然把它们拖到一起配对，合并面板会变红并阻止合并，提示先取消配对、换一个方向。

![负数预警](preview-negative.png)

## 题库与难度

### 第一层：基础移项（1–4）

只有一边有 x，主要练习“跨过等号，加变减、减变加”。其中 `12 - x = 5` 的 x 是减数，需要先把 `-x` 搬到右边。

### 第二层：带 3x 的方程（5–10）

x 前面有数字，解完移项后还要把这个数字搬到另一边变成除法。`3x + 2 × 4 = 14` 会先把 `2 × 4` 算成 `8`，再按 `3x + 8 = 14` 操作。

### 第三层：同边先合并（11–13）

同一边出现多个 x 项，需要先把两个 x 项拖到一起配对，再填合并后的 x 前面的数。数字之间不用配对。

### 第四层：两边都有 x（14–18）

两边都有 x，也有常数。先选择正确方向把 x 搬到同一边，再搬数字、配对 x 项、除以这个数。

### 第五层：带负 x 的挑战（19–22）

出现 `-2x`、`-4x`、`-7x`、`-9x`。程序会优先把负的 x 项搬到另一边，避免合并后出现负数。

| 关卡 | 方程 | 难度与关键步骤 | 答案 |
| --- | --- | --- | --- |
| 1 | `x + 5 = 12` | 基础：加号搬家 | `x = 7` |
| 2 | `x + 3 = 8` | 基础：加号搬家 | `x = 5` |
| 3 | `x - 2 = 5` | 基础：减号搬家 | `x = 7` |
| 4 | `12 - x = 5` | 基础：x 是减数，先搬 `-x` | `x = 7` |
| 5 | `5x = 35` | 先搬 5x 里的 5，再除以 5 | `x = 7` |
| 6 | `3x = 12` | 先搬 3x 里的 3，再除以 3 | `x = 4` |
| 7 | `4x + 2 = 18` | 先搬 2，再除以 4x 里的 4 | `x = 4` |
| 8 | `2x - 7 = 3` | 先搬 -7，再除以 2x 里的 2 | `x = 5` |
| 9 | `3x + 2 × 4 = 14` | 先算 `2 × 4 = 8`，再解 `3x + 8 = 14` | `x = 2` |
| 10 | `5x + 13 = 33` | 先搬 13，再除以 5x 里的 5 | `x = 4` |
| 11 | `7x - 2x = 35` | 同边合并：配对两个 x | `x = 7` |

## 操作说明

- **拖动整项**：按住数字，或按住 `x` 所在的卡片，拖到等号另一边，符号会变反。
- **拖动 3x 里的 3**：按住 `3x` 左边金色的 `3`，拖到另一边，`×3` 会变成 `÷3`。
- **配对合并**：在带多个 x 项的关卡里，把一个 x 项拖到另一个 x 项上，出现连线后直接填“合并后是几 x”，再点“合并”。界面上不显示原算式，也不提示计算步骤。
- **数字合并**：数字之间不需要拖动配对，点“算一算”会自动算成一个数。
- **算一算**：当 x 都在一边、数字都在另一边时亮起。有多个 x 项时，要先完成配对。
- **提示**：默认不显示具体操作；点“提示”后才会标出建议搬动的项、3x 里的 3，或需要配对的两个 x 项，并显示一步提示。
- **撤销**：回到上一步，也可以按 `Ctrl + Z`。
- **重来**：重新开始当前关卡。
- **下一题 / 关卡圆点**：完成当前关后解锁下一关；已完成的关卡可以回看。
- **音效**：右上角可关闭，设置会保存在本机。
- **键盘**：`Tab` 聚焦到项或金色数字，按 `Enter` 或空格执行对应的移动；`Ctrl + Z` 撤销。

## 关卡锁定与开发者模式

默认按顺序闯关：

- 一开始只解锁第 1 关。
- 算出当前关的答案后，下一关才会解锁，“下一题”按钮也会亮起。
- 未解锁的关卡圆点是虚化状态，点击会提示先完成前面的关卡。
- 已完成的关卡可以重新进入复习。

开发者模式（给老师调试、演示或临时跳关）：

- 连续点击页面左上角的标题 **“等号搬运工” 5 次**（2.5 秒内）。
- 标题旁会出现 `DEV` 标记，全部关卡解锁，“下一题”不再受限制。
- 再连续点击标题 5 次可以关闭开发者模式。
- 开发者模式只在当前页面会话有效，刷新页面后恢复普通模式。

## 设计意图

- **先看见，再计算**：把“移项变号”和“3x 里的 3 变除”都做成可见的动作，而不是先背规则。
- **实时预览**：拖到等号另一边时，幽灵卡片会提前显示 `+3 → -3` 或 `×3 → ÷3`。
- **原式先行**：顶部固定显示原方程，不提前给出“搬哪一项”的答案；操作提示只在点“提示”后出现。
- **保留中间状态**：移项后不自动合并，先呈现 `8 - 3`、`3x - x`，让学生看到过程。
- **负数预警**：同边 x 项合起来会是负数时标红，提醒学生先调整方向，避免越算越乱。
- **手动配对**：在进阶关里，学生要自己找出两个 x 项、拖到一起、填写合并后的 x 前面的数；界面不提供算式提示。
- **数字自动合并**：数字之间不增加额外操作，交给“算一算”完成，降低重复拖拽的负担。
- **分步处理**：两边都有 x 时，先搬 x，再搬数字，再配对 x 项，再除以这个数。
- **代回检验**：解出后自动生成检验式，强化“答案要放回原式检查”的习惯。
- **不惩罚试错**：拖错、拖回、撤销都可以，重点在观察规律。

## 自定义题目

打开 `app.js`，修改顶部的 `LEVELS` 数组即可：

```js
const LEVELS = [
  { equation: "x + 5 = 12", note: "加号搬家" },
  { equation: "6x = 24", note: "3x 关卡" },
  { equation: "4x + 3 = x + 12", note: "两边都有 x", manualCombine: true }
];
```

`manualCombine: true` 会让这一关启用“拖拽配对 + 手动填写合并后的 x 前面的数”；不加这个标记时，仍然用“算一算”自动合并。

当前版本支持：

- 整数、`x`、加号、减号、等号；
- `3x` 这样的写法；
- 一边或两边都有 x，以及同一边有多个 x 项；
- 拖拽两个 x 项配对，手动填写合并后的 x 前面的数；
- 数字自动合并，通过拖 3x 里的 3 完成除法；
- `2 × 4` 这种“数字乘数字”的常数乘积会先自动算成一个数。

后续增加题目时，直接往 `LEVELS` 数组里追加即可，关卡圆点、进度和“全部通关”数量会自动适配。

暂不支持括号、分数、含 x 的乘除、负数解，也不建议在一个方程里使用多个未知数。自定义题目时要保证最后能得到整数解。

颜色、圆角和字体可以在 `styles.css` 顶部的 `:root` 变量中统一调整。
