3x → ÷3
遇到 3x 怎么办？

拖住 3x 里的金色 3 跨过等号，×3 会变成 ÷3；拖 3x 的 x 部分，则是把整项移项。

2x → x + x
两边都有 x？

先把 x 搬到同一边，再点“算一算”把它们合起来。

小提醒：只有跨过等号，符号或运算才会变反。
为什么？移项要变号、系数要变除，都是为了让等号两边仍然一样重。
